# Feature ideas

Ideas noted for later. Not scheduled or designed yet.

## AI-assisted Facebook post (for Rachel)

**Idea:** Rachel adds a picture and a few rough words; an AI tidies up the
text into a better post; it then gets posted to Facebook.

Rough flow:

1. Rachel uploads a photo and types a short note (a few words is fine).
2. An AI rewrites the note into a polished post: fixes spelling and
   grammar, improves the wording, keeps it in her voice.
3. Rachel sees the suggested post next to the photo and can edit it,
   regenerate it, or approve it.
4. On approval, the photo and text are posted to Facebook.

Open questions:

- Which Facebook destination: a Page or a personal profile? Posting via
  the Graph API works for Pages; posting to personal profiles is not
  supported by the API.
- Always require Rachel's approval before posting (recommended), or allow
  auto-post?
- Should the AI also suggest hashtags or a caption length?
